## 一、支持设备（双屏：方屏 + 圆屏，按屏幕形状声明）

app.json 按官方 v3 屏幕适配规范只声明**一个构建目标 `gt`**，屏幕特征写在 `platforms` 里
（`{"st": "r"}` 圆屏、`{"st": "s"}` 方屏），构建期自动按形状分包，无需逐个枚举设备：

```json
"targets": {
  "gt": {
    "platforms": [{ "st": "r" }, { "st": "s" }],
    "designWidth": 390
  }
}
```

`zeus build` 由这两个声明产出 **12 个分包（7 圆屏 + 5 方屏）**，覆盖运行版本达标
（minVersion 3.0.0）的全部 83 个 deviceSource（圆屏 65 + 方屏 18）、共 8 个分辨率档：

| 屏幕 | 分辨率 | deviceSource 数 | 代表性机型 |
|---|---|---|---|
| 圆屏 `st:"r"` | 480×480 | 35 | Amazfit Balance / Balance 2 / Balance 3 / Balance Ultra / T-Rex 3 / T-Rex 3 Pro (48mm) / T-Rex Ultra 2 / Cheetah Pro / Cheetah 2 Ultra / Active Max |
| 圆屏 `st:"r"` | 466×466 | 22 | Amazfit GTR 4 / GTR 4 Limited Edition / Active 2 (Round) / Active 2 NFC (Round) / Active 3 Premium / Cheetah 2 Pro / T-Rex 3 Pro (44mm) |
| 圆屏 `st:"r"` | 454×454 | 4 | Amazfit T-Rex Ultra / Cheetah (Round) |
| 圆屏 `st:"r"` | 416×416 | 2 | Amazfit Falcon |
| 圆屏 `st:"r"` | 360×360 | 2 | Amazfit Active Edge |
| 方屏 `st:"s"` | 390×450 | 14 | Amazfit GTS 4 / Cheetah (Square) / Active / Bip 6 / Rome / Active 2 (Square) / Active 2 NFC (Square) |
| 方屏 `st:"s"` | 320×380 | 3 | Amazfit Bip 5 Unity / Bip 5 Core |
| 方屏 `st:"s"` | 432×514 | 1 | Amazfit Bip Max |

技术要点：

- **同一套页面代码**，构建期由 `zosLoader:./shape.[pf].layout.js` 把 `[pf]` 换成
  `r` / `s`，圆屏包只含圆屏版面常量、方屏包只含方屏版面常量，运行期不需要判断屏幕形状。
- **方屏**沿用原 390×450 版面，按实时屏幕尺寸推导安全边距与卡片几何，兼容
  390×450 / 432×514 / 320×380 三档，GTS 4 上的已验收版式逐像素不变。
- **圆屏**按 390×390 设计画布重新排布纵向节奏，内容带压进内接圆安全区
  （`x 45, y 81, w 300, h 228`），页头按所在行的弦宽收窄（标题行 198、副标题行 270）。
- 最低 API 3.0，未包含 GTS 3、GTS 4 mini 等 Zepp OS 1.0/2.x 或低版本机型；带状屏 `st:"b"`
  未声明（应用面向手表，无带状屏版面）。

## 二、应用简介（商店列表栏，短版）

宽基指数行情：在 Zepp OS 手表上查看 A 股核心宽基 ETF 的实时行情、指数 PE 五年估值、基金份额与资金流，支持自选持仓收益计算与买卖信号预警，负一屏提供 M1-M2 剪刀差快捷卡片。方屏与圆屏均已适配。数据由手机端联网获取，手表本地展示。

## 三、应用详细介绍

宽基指数行情（原 ETFstudio）是一款面向 Zepp OS 手表的宽基指数 ETF 行情工具，覆盖沪深 300、中证 500、中证 1000、中证红利、创业板、科创 50 等 6 个核心宽基 ETF。同一套页面同时适配方屏与圆屏：方屏沿用 390×450 版面，圆屏按内接圆安全区重新排布。负一屏另附 M1-M2 剪刀差快捷卡片。

主页 6 屏：
1. 市场温度——宽基指数整体估值与市场情绪概览。
2. 核心标的——6 个 ETF 实时行情、涨跌与关键指标卡片。
3. 智能信号——基于均线、估值分位、资金流等因子给出的分批买入／持有／观察／减仓／清仓参考信号。
4. 自选持仓——按成本价与仓位实时计算各 ETF 收益。
5. 预警记录——历史信号触发记录。
6. 设置入口。

统一详情页 6 屏：详细、分时／日 K、资金流、基金份额、融资融券、PE 五年估值。

主要特性：
- 行情、估值、份额、资金流数据由 Zepp 手机端 Side Service 直连公开财经接口获取，再经蓝牙同步至手表，电脑无需在线。
- 34 种系统语言全量国际化，采用 Noto Sans / Zepp OS Number 设计字体。
- 布局、安全边距与卡片几何按各机型屏幕实时推导：方屏兼容 390×450 / 432×514 / 320×380，
  圆屏按 360 / 416 / 454 / 466 / 480 各档的内接圆弦宽收窄。构建期按屏幕形状分包，两套版面互不影响。
- 快捷卡片（负一屏）：M1-M2 剪刀差及近 13 个月走势，点击回到应用；卡片只读手表本地快照，
  不自行联网（符合 Zepp OS 对快捷卡片的能力限制）。
- 前台优先渲染、最小常驻、有界缓存与失败保留上一帧有效数据，兼顾流畅度与弱网可用。

免责说明：本应用展示的所有行情、估值与信号仅供参考，不构成任何投资建议；公开数据源可能存在延迟或误差，请以交易所与基金公司公告为准。

## 四、隐私声明

1. 不收集、不上传任何个人身份信息：应用不要求注册、登录，不采集姓名、手机号、位置、通讯录、健康数据等个人信息。
2. 本地存储内容：手表端仅在设备本地存储用户主动配置的自选持仓（成本价、仓位）、默认标的、预警阈值和信号缓存；这些数据保存在手表本地，不上传至任何服务器，卸载即清除。
3. 联网行为：手机端 Side Service 在使用时向公开财经数据接口发起 HTTP(S) 请求，仅请求行情、估值、份额、资金流等公共市场数据，请求中不包含用户个人标识。数据源域名：push2/push2his/datacenter-web/fundf10.eastmoney.com、stock.xueqiu.com、web.ifzq.gtimg.cn/qt.gtimg.cn、query.sse.com.cn、www.szse.cn、legulegu.com。
4. 不接入广告、不接入第三方统计或追踪 SDK。
5. 不采集心率、血氧等任何健康传感器数据；不使用定位功能。
6. 应用内提示语"手机联网请求失败／数据源暂时熔断"等仅为本地网络状态提示，不向外部上报。

## 五、调用权限

| 权限项 | 是否使用 | 用途说明 |
|---|---|---|
| 无 | 否 | 应用需要联网与本地存储等能力，非"无权限"类 |
| 心率 | 否 | 不读取心率/血氧等任何健康传感器数据 |
| 连接网络 | 是 | 手机端 Side Service 联网获取 ETF 行情、估值、份额、资金流等公开数据 |
| 定位 | 否 | 不使用 GPS/位置信息 |
| 后台运行 | 是 | 手机端 Side Service 在空闲时进行历史数据同步与行情预取，为手表展示准备缓存数据 |
| 其他 | 是 | 手表端通知（notification）与振动（Vibrator）：用于买卖信号到达时的提醒与振动；本地存储（local_storage）：保存自选持仓与设置；设备信息（device.info）：读取屏幕尺寸以推导布局 |

对应 app.json 已声明 permissions：`data:os.device.info`、`device:os.local_storage`、`device:os.notification`。

1. 本包为宽基指数行情 1.0.0（versionCode 100），configVersion v3，API 目标 3.5.0、最低 3.0.0。app.json 以官方 v3 屏幕适配规范声明单个构建目标 `gt`，`platforms` 为 `[{"st":"r"},{"st":"s"}]`；`zeus build` 据此产出 12 个分包（7 圆屏 + 5 方屏），覆盖全部 8 个分辨率档、83 个达标 deviceSource（圆屏 65 + 方屏 18，明细见第一节）。
