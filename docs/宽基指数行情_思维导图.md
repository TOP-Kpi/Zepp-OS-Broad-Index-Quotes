# 宽基指数行情（ETFstudio）项目源码思维导图

## 项目总览
### 应用基本信息
  - 类型：Zepp OS 手表小程序(App)，appName=宽基指数行情
  - package=etfstudio-dualscreen，版本 1.0.0（version.code=100）
  - 目标设备：单工程双屏——方屏（390×450 / 432×514 / 320×380）与圆屏（360/416/454/466/480）
    共 83 个达标 deviceSource（圆屏 65 + 方屏 18），`app.json` 用官方 v3 形状声明 `platforms:[{st:"r"},{st:"s"}]`
  - 运行时最低 3.0 / 目标 3.5；构建期按形状分包，运行期不判断屏幕形状
### 架构一句话
  - 设备端 page+utils 画 UI（QuickJS/Canvas/TEXT）＋ 34 语言 i18n
  - 手机端 app-side 联网取数（东财/腾讯回退/乐咕雪球PE/沪深份额）
  - 经蓝牙 compact 压缩回传；离线用 history 132日库兜底
### 主要页面结构
  - 首页：市场温度/宽基行情/智能信号/自选持仓/预警记录/设置（6屏）
  - 列表页：8 只核心宽基 ETF 卡片
  - 详情页：详细/分时·日K/资金流/基金份额/融资/PE五年估值（6屏）
### 功能要点
  - 双向语言全量国际化（t()/tf()）+ 设计字体子集化
  - 有界资源、生命周期隔离、缓存优先+静默刷新、弱网熔断回退
  - 目标：解决旧版在 GTS4 卡顿/重启，设计语言“磨砂玻璃/光影/温暖”

## 根目录关键文件

### app.json

### package.json

### setting 目录
  - ★手机端 Companion 设置页（自选持仓/默认ETF/信号阈值等 settingsKey 契约）
### 其他根文件
  - BUILD_VALIDATION.txt（v1.0.1 旧验收记录，待更新/归档）
  - sim-debug.log（模拟器日志，临时，建议清理）
  - jsconfig.json / global.d.ts（编辑器/类型）
  - icon/字体资源见 assets 与 tools/fonts-src 目录

## app-side（手机 Companion 数据层 ★★★）
### 总入口与传输
  - index.js：★总调度，onRequest→routeRequest→compact 压缩回传
  - config.js：数据源 URL/超时/缓存时长配置中心
  - history-db.js：历史库对外门面（re-export）
  - shares-cache.js：基金份额近6月持久缓存与合并
### domain（编排/纯计算 ★）
  - request-router.js：★★请求路由＋联网失败按需回退（dashboard/overview/…/share）
  - signal.js：★★★多因子买卖信号打分核心算法（deriveSignal→action/reasons）
  - market.js：市场温度/广度 regime 判定
  - portfolio.js：自选持仓回报计算（本地设置+实时价）
  - settings.js：设置读取与蓝牙瘦身投影
  - compact.js：响应抽稀压缩（省 BLE 带宽）
### history（离线历史库 132日 ◆◆）
  - store.js：历史库读写持久根（JSON/版本清洗/30s memo）
  - record-builder.js：把日级原始数据固化为逐日记录(+MA5/20/60+signal)
  - sync.js：后台同步编排（前台静默才跑、并发/让路）
  - fallback.js：联网/缺史失败时转回退结构兜底
  - config.js/value.js：常量 + 纯日期/均线小工具
### providers（数据源适配 ◆◆）
  - eastmoney.js：★Provider 工厂装配层
  - transport.js：★★★全仓最重要的网络传输+缓存+熔断底层
  - quote.js/quote-parser.js：实时行情（东财主源+腾讯回退）
  - chart.js/overview.js：K线分时/总览聚合(含 light 加速首帧)
  - flow.js/margin.js：资金流/融资融券
  - shares*.js：份额(SSE 快照/SZSE 日频/archives 回退 + share-parser)
  - universe.js：全标的自选行情+信号
  - valuation*.js：指数 PE 估值（乐咕主/雪球回退，五年分位，含 MD5/CSRF）

## utils（手表端共享工具库 ★★★）
### 基础工具
  - compat.js：QuickJS 兼容纯函数（ES5·无分号风格约定）
  - constants.js：调色板/主题/8只ETF/缓存TTL/安全区/TEXT 字体等元数据
  - format.js：固定位数/亿万元缩写/红绿配色等格式化
  - view-state.js：◆视图渲染指纹，避免无变化重绘
### 数据与生命周期
  - data.js：★★“缓存优先+请求”requestWithCache 公共取数通道
  - storage.js：★★多级缓存/告警历史（内存 LRU+localStorage，自愈淘汰）
  - runtime.js：★★页面 runtimeGeneration 存活守卫（防止旧回调写新页）
  - refresh.js：◆自动刷新/懒加载调度（交互空闲门控）
  - signals.js：★★智能信号通知/告警（变化才振动+系统通知）
  - i18n.js / i18n-data.js：★★设备端两/层翻译（po 失败兜底；data 为自动生成勿手改）
### UI 画布与交互
  - ui/scene.js：★★★Canvas 场景生命周期 + 原生绘制安全层（防崩溃地基）
  - ui/charts.js：★★★图表绘制族（折线/K线/面积/柱状/双轴图）
  - ui/components.js：★★通用玻璃卡/量表/信号胶囊/评分环（含 safeFontFor 修复缺字）
  - ui/interaction.js：★★每 Canvas 单一触摸监听+命中区(BUTTON)
  - ui/motion.js / ui/vscroll.js：有界评分动效 / 纵向滚动条控件
  - ui/index.js / navigation/index.js：各自职责域的转发门面（保持页面 import 稳定）
### navigation（横向翻页调度 ★★）
  - scenes.js：★★★分区场景调度中枢（首屏预载/脏页延时/窗口裁剪）
  - window.js：相邻页驻留窗口 + 分区定时器登记清理
  - route.js：safePush 路由防抖/去重
  - swiper.js / scrollbar.js：Swiper 容器 / 原生 PAGE_SCROLLBAR

## page（Zepp OS 页面 ★★★）
### home（首页 6 屏）
  - index.page.js：★首页 Controller（6 分页容器+自动刷新+渲染分发）
  - model.js：首页纯数据层状态模型
  - services/(6)：dashboard/signal/portfolio/alerts/history/liquidity 取数逻辑
  - views/(7)：market/universe/signal/portfolio/alerts/settings/common 渲染+点击
### universe（核心标的列表 6 只）
  - index.page.js：★Controller（6 屏 swiper + 资源交还时机 leaveToDetail）
  - model.js：纯数据层状态（合并 dashboard 的 universe 与 market.items）
  - services/(1)：universe 取数（一次 dashboard 请求喂满 6 屏）
  - views/(1)：detail 单标的整页绘制 + 底部入口按钮绑定
### detail（单标的数据 6 屏）
  - index.page.js：★详情 Controller（解析 code+name，按可见页拉对应 service）
  - model.js：market 数值数学（分时压缩时间轴/日K蜡烛+均线）
  - services/(6)：overview/chart/flow/shares/margin/valuation
  - views/(7)：对应各屏绘图 + drawHalfGauge 量表/ PE 面积图
### page/i18n
  - 34 语言 .po（128 条/语言；msgid 中文原文）→由 tools/build_i18n.py 生成，勿手改

## app-widget（快捷卡片 / 负一屏）
  - index.js：★M1-M2 剪刀差卡片。绘制区=卡片本身，尺寸来自 getAppWidgetSize()；
    不用 px()、不用 GROUP/SCROLL_LIST/VIEW_CONTAINER；只读本地快照、只响应点击。
    刻意不调 setAppWidgetSize（官方返回值语义不明确，会导致版面与实际高度错位）。
  - 规范对应与取舍见 docs/SHORTCUT_CARD.md；契约在 utils/m1m2.js

## tools（构建期工具，不进包 ◆）
  - build_i18n.py：★生成 34 份 po（缺译拒收，会扫 page/ 与 app-widget/ 的 t()/tf()）
  - subset_fonts.py：★字体子集化，输出目录由 app.json 形状声明推导→assets/gt.r|gt.s/fonts
  - verify-font-glyphs.py：校验子集字体覆盖全部译文用字（缺字在真机上才是豆腐块，别的检查看不见）
  - i18n-report.py：词条双向一致性校验
  - dead-exports.py / unused-imports.py：死代码/未用导入静态扫描
  - render-preview.js：★★★vm 桩掉 @zos，把真实渲染代码转 SVG 出预览页（--round 出圆屏版；含卡片帧）
  - render-compare.cjs：方屏/圆屏并排对照画册
  - verify-frames.cjs：逐帧校验（r=圆内+内容带+不叠字硬闸门；s=越界清单对基线）
  - verify-card.cjs：卡片版面校验（圆角背景/内容不出卡/16px 边距/走势图存在/文字不重叠）
  - structure-report.cjs：由 app.json 与实际文件树生成 docs/project_structure_report.txt

## 维护提示与风险点
### 待清理项
  - preview/ 为生成物，改代码后勿手改
  - 工程内不要放第三方 .js（zeus 会把根目录下所有 .js 当源码扫描）
### 冗余/优化建议①
  - “8 只标的”字典散落 5 处（constants/universe/setting/portfolio/history·common），建议收敛单源
### 冗余/优化建议②
  - 改导航/定时器（window+scenes 关键路径）务必回归 test:navigation(-behavior)
### 改动路径提醒
  - 改文案：代码词条→npm run i18n→npm run render；勿手改 po/i18n-data
  - 增删请求 method：同步 request-router.handlers + device 常量 + tests
  - 改数据源接口：最好先跑 test:data；设备端禁 async/await（ES5 风格）
